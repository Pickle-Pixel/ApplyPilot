- The tailor judge prompt's "TOLERANCE RULE" (up to 3 minor stretches, including "any LEARNABLE skill") creates a controlled-fabrication pipeline by design.

## 5. Cover letter prompt audit

### 5a. LLM prompt (`scoring/cover_letter.py::_build_cover_letter_prompt`)

Reads:

- `profile.personal.preferred_name` for sign-off.
- `profile.skills_boundary` flattened as the only allowed tools.
- `profile.resume_facts.real_metrics` filtered by role (insurance vs non-insurance).
- `profile.resume_facts.preserved_projects` if any.

Prompt language:

- "Use ONLY numbers that already appear in the resume or in the approved real-metrics list — NEVER invent a percentage, dollar figure, or count."
- "FABRICATION = INSTANT REJECTION: The candidate's real tools are ONLY: {skills_str}. Do NOT mention ANY tool not in this list."
- "NEVER attribute a bullet from one employer to a different employer (no swapping who did what)."
- Role guardrail blocks insurance license mentions for non-insurance roles.

**Verdict on the LLM prompt itself: clean.** The instructions correctly cite profile.json, prohibit invented numbers, and forbid attribution swaps. If this path runs, output should be defensible.
