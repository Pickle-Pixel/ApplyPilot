# Pack Quality Gate

Pre-submit checklist for any tailored resume + cover letter pack. Run before clicking apply.

## Checklist
- [ ] Cover letter names the actual company (not "your team")
- [ ] No fabricated percentages. Every `%` traces to `profile.json` `real_metrics`
- [ ] No false software/tool claims (e.g., NICE WFM at NCO when NCO used Aspect eWFM)
- [ ] Email reads correctly (dual-format `bibyd21 | darrinbiby243` is intentional)
- [ ] Resume employer list is subset of master (no invented employers)
- [ ] No `[BRACKETED]` placeholders anywhere
- [ ] Cover letter opens with company-specific hook, not template phrasing
- [ ] PDF rendered cleanly, no corruption

## Reference
This file: `Projects\dev\ApplyPilot\templates\pack_quality_gate.md`

## On failure
If any box is unchecked, do NOT submit. Either fix the pack or kick back to manual review.
